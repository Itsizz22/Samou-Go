# Yatta Go interface review — 2026-09-10

Observed directly on the connected Samsung A34 (com.yattago2.twa). Read-only browsing: home, expanded categories, Qishta store and product image viewer. No order, account change, payment or message was submitted.

## Observations and proposed Samou improvements

1. Photo-based categories in a compact grid, with More expanding inline. Improve Samou category artwork and avoid excessive initial scrolling.
2. A prominent most-requested section inside a store. Use actual order aggregates, not random products labelled popular.
3. Tapping a product photo opens a larger viewer. Add or improve this without accidentally adding an item to the cart.
4. Store identity, open status, opening hours and estimated duration grouped together. Keep Samou delivery fee display rules unchanged.
5. Persistent, easy-to-reach cart action. Refine the existing Samou cart bar with visible item count and product subtotal; avoid oversized navigation covering products.

The commercial app's artwork and logo were not copied. These are proposals, not implemented design changes.
